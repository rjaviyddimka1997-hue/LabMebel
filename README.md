# LabMebel — 3D-визуализация мебели для клиента

Сервис для мебельщиков: собрать изделие по замерам, показать клиенту в 3D,
тут же получить раскрой, смету и коммерческое предложение.

Работает целиком в браузере — без сервера, регистрации и базы данных.
Проект помещается в ссылку, поэтому клиенту достаточно отправить её в мессенджер.

## Что умеет

**Конструктор.** Модуль задаётся габаритами, толщиной плиты, типом опоры и задней
стенки. Внутри — секции произвольной ширины: полки, ящики, штанга или пусто.
Спереди — распашные двери, две двери, фасады ящиков, подъёмный механизм или
открытая ниша. Из этих кирпичиков собирается кухня, шкаф, стеллаж, комод,
ТВ-тумба, тумба в ванную.

**3D в реальном времени.** Комната с полом, стенами и плинтусом, мягкие тени,
процедурные текстуры ЛДСП, МДФ и шпона (без внешних файлов). Модули двигаются
мышью по полу с шагом 10 мм и примагничиваются к стенам. Ракурсы «Обзор»,
«Фронт», «Сверху», «В комнате». Режим «Открыть фасады» показывает клиенту
наполнение: двери распахиваются, ящики выезжают.

**Раскрой и смета.** Изделие автоматически разбирается на детали: боковины,
дно, крыша, полки, стойки, короба ящиков, фасады, столешница. Одинаковые детали
группируются в карту раскроя (её можно выгрузить в CSV), считается погонаж
кромки 2 мм и 0.4 мм, петли, направляющие, подъёмники, опоры, крепёж и ручки.
Поверх материалов накидывается работа и наценка — оба процента настраиваются.

**Выдача клиенту.** Ссылка в режиме просмотра (без цен по себестоимости и без
редактирования), PNG-рендер и коммерческое предложение с реквизитами
мастерской, составом заказа и итогом — печатается в PDF средствами браузера.

## Запуск

```bash
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # посмотреть прод-сборку
npm test         # тесты доменной логики
npm run typecheck
```

`dist/` — статика, кладётся на любой хостинг: GitHub Pages, Netlify, обычный nginx.

## Как устроено

```
src/
  domain/          # предметная область, не знает про React и three.js
    types.ts       # модель проекта: комната, модули, секции, цены
    materials.ts   # каталог ЛДСП/МДФ/шпона/столешниц и прайс на фурнитуру
    builder.ts     # параметры модуля → список деталей с координатами
    estimate.ts    # детали → карта раскроя и смета
    presets.ts     # готовые изделия
    share.ts       # проект ⇄ ссылка (deflate + base64url)
    storage.ts     # проекты в localStorage
  viewer/
    scene.ts       # three.js: сцена, свет, выбор и перетаскивание модулей
    textures.ts    # процедурные текстуры и подписи размеров
  ui/              # React-панели: список модулей, редактор, смета, КП
```

Ключевая идея — `buildUnit()`: он единственный знает, как изделие раскладывается
на детали. От него питаются и 3D-сцена, и раскрой, и смета, поэтому картинка
клиента и цифры в смете не могут разойтись.

Все размеры в модели — в миллиметрах; в three.js переводятся в метры (`S = 0.001`).

## Цены

Цены материалов (`materials.ts`) и фурнитуры (`HARDWARE_PRICES`) — ориентир,
их нужно заменить своими закупочными. Проценты работы и наценки, а также
доставка правятся прямо в интерфейсе, на вкладке «Проект».
Коэффициент отхода при раскрое — `WASTE_FACTOR`, по умолчанию 12%.
