# 03. UX: User Flow, информационная архитектура, структура экранов, прототипы

## 1. Принципы проектирования (конституция продукта)

1. **Правило 3 тапов до ценности.** От запуска до «я вижу выезд, на который могу поехать» — максимум 3 тапа, без регистрации.
2. **Регистрация только по действию.** Просим авторизоваться в момент, когда человек нажимает «Присоединиться», а не на входе.
3. **Проектируем под перчатку и солнце.** Тап-таргет ≥48 px, контраст ≥4.5:1, ключевые действия в нижней трети экрана.
4. **Офлайн — не фича, а требование.** В лесу нет сети. Всё, что нужно на выезде, кешируется заранее.
5. **Уровень сложности виден везде.** На карточке маршрута, выезда, в профиле райдера. Это наш категорийный стандарт.
6. **Приватность по умолчанию.** Старт и финиш трека обрезаются на 500 м. Точная геопозиция человека не показывается никогда — только город/район.

## 2. Шкала сложности EnduroHub (E1–E5) — ключевая онтология продукта

| Уровень | Название | Описание | Техника | Опыт |
|---|---|---|---|---|
| **E1** | Грунт | Грейдеры, полевые дороги, лесные просеки. Сухо. | Любая, включая туристов | Первый сезон |
| **E2** | Лайт-трейл | Колея, песок, небольшие подъёмы, броды до 20 см | Эндуро/двойник | 1 сезон |
| **E3** | Трейл | Глина, корни, крутые подъёмы, броды до 50 см. Падения вероятны | Эндуро с внедорожной резиной | 2+ сезона |
| **E4** | Хард-трейл | Болото, завалы, затяжные технические участки. Нужна физподготовка | Подготовленное эндуро | 3+ сезона |
| **E5** | Хард-эндуро | Экстремальный рельеф, спецучастки, лебёдка/помощь. | Подготовленное хард-эндуро | Соревновательный уровень |

Каждому маршруту присваивается уровень **автором + подтверждается голосованием прошедших**. Расхождение >1 уровня помечает маршрут как спорный.

## 4. User Flow — ключевые сценарии

### 4.1. Flow A: Первый запуск → первый выезд (главная воронка)

```
[Открыл Mini App из чата]
   │
   ▼
[Экран карты с выездами рядом]  ← БЕЗ регистрации, геолокация по IP
   │  (определили город, показали 5 ближайших выездов)
   ▼
[Тап на карточку выезда]
   │
   ▼
[Карточка выезда: дата, уровень E2, 6/10 участников, маршрут 84 км]
   │
   ├─ «Слишком сложно» ──► [Фильтр по уровню] ──► возврат в ленту
   │
   ▼
[Тап «Присоединиться»]
   │
   ▼
[Регистрация: 1 тап через Telegram] ← точка конверсии
   │
   ▼
[Мини-онбординг: 3 вопроса]
   │   1. Твой уровень? (E1–E5, с подсказкой «не уверен — ставь E1»)
   │   2. Какая техника? (поиск по моделям / «пока нет»)
   │   3. Город
   ▼
[Заявка отправлена / Вы в группе]
   │
   ▼
[Пуш организатору: «Дмитрий (E2, Honda CRF250L) хочет присоединиться»]
   │
   ▼
[Подтверждение] ──► [Чат выезда] ──► [За 24ч: пуш с чек-листом и точкой сбора]
   │
   ▼
[День выезда: экран «Активный выезд» — офлайн-карта, запись трека, SOS]
   │
   ▼
[После: «Как покатали?» → оценка маршрута + загрузка фото + отметка участников]
   │
   ▼
[Достижение «Первый выезд» + предложение подписаться на организатора]
```

**Целевые метрики воронки:**
| Шаг | Конверсия | Обоснование |
|---|---|---|
| Открыл → посмотрел карточку | 55% | Контент должен цеплять сразу |
| Карточка → тап «Присоединиться» | 18% | Много «смотрящих» на первом заходе |
| Тап → регистрация | 78% | Telegram-авторизация почти без трения |
| Регистрация → завершил онбординг | 85% | 3 вопроса, можно пропустить |
| Заявка → реально поехал | 62% | Отвал на погоде и планах |
| Поехал → второй выезд за 60 дней | 45% | Ключевая метрика ценности |

### 4.2. Flow B: Создание выезда (для лидера)

```
[FAB «+» на карте или в ленте] → [Создать выезд]
   │
   ▼
ШАГ 1 — Маршрут
   ├─ Выбрать из моих маршрутов
   ├─ Выбрать из карты
   ├─ Импортировать GPX
   └─ «Определимся на месте» (без маршрута)
   │
   ▼
ШАГ 2 — Когда и где
   ├─ Дата (быстрые чипы: Суббота · Воскресенье · Выбрать)
   ├─ Время сбора
   └─ Точка сбора (карта, поиск, «моя частая точка»)
   │
   ▼
ШАГ 3 — Кто
   ├─ Уровень E1–E5 (подтягивается из маршрута, можно изменить)
   ├─ Количество мест (2–30)
   ├─ Тип: открытый / по заявке / по ссылке
   └─ Требования (галочки: защита обязательна, свой бензин, опыт бродов)
   │
   ▼
ШАГ 4 — Описание
   ├─ Название (автогенерация: «E2 · Лосиный остров · 84 км · Сб 12 окт»)
   ├─ Текст (опционально)
   └─ Чек-лист снаряжения (шаблон по уровню, редактируемый)
   │
   ▼
[Опубликовать]
   │
   ▼
[Автопост в связанные Telegram-чаты] + [Пуш подходящим райдерам в радиусе 100 км]
   │
   ▼
[Экран управления: заявки, чат, изменить, отменить]
```

**Целевое время прохождения: 40–90 секунд.** Это гипотеза H7.

### 4.3. Flow C: Запись ТО в гараже

```
[Гараж] → [Мой KTM 350 EXC-F] → [+ Запись обслуживания]
   │
   ▼
[Тип работы] (чипы: Масло ДВС · Воздушный фильтр · Цепь/звёзды · Вилка · Амортизатор
               · Тормозная жидкость · Свеча · Резина · Другое)
   │
   ▼
[Детали]
   ├─ Дата (по умолчанию сегодня)
   ├─ Пробег / моточасы (подставляется последний + предложение)
   ├─ Стоимость запчастей / работ
   ├─ Кто делал: сам / мастер из каталога / другой сервис
   └─ Фото чека или заметка
   │
   ▼
[Сохранить]
   │
   ▼
[Автоматически: пересчёт следующего ТО по регламенту → напоминание]
   │
   ▼
[Экран сводки: «За сезон потрачено 87 400 ₽. Это на 12% больше прошлого»]
```

### 4.4. Flow D: Бронирование тура (монетизация)

```
[Витрина туров] → [Фильтр: уровень E3, даты, регион]
   │
   ▼
[Карточка тура: 3 дня, Карелия, E3, 42 000 ₽, 4/10 мест, гид Игорь ★4.9 (37 отзывов)]
   │
   ▼
[Забронировать] → [Анкета: уровень, техника (своя/аренда), опыт, контакты]
   │
   ▼
[Предоплата 30% через эквайринг] ← здесь наша комиссия 10%
   │
   ▼
[Бронь подтверждена] + [Чат тура] + [Напоминания за 14/3/1 день]
   │
   ▼
[После тура: запрос отзыва] → [Отзыв в профиль гида] → [Рекомендация похожих туров]
```

### 4.5. Flow E: Аварийный сценарий (SOS)

```
[Активный выезд] → [Долгое нажатие SOS 3 сек]
   │
   ▼
[Экран SOS]
   ├─ Мои координаты крупным шрифтом (копируются в один тап)
   ├─ Ближайшая точка выезда для эвакуации (из карты маршрута)
   ├─ «Отправить участникам выезда» (через Telegram, работает по SMS-fallback)
   └─ Номера экстренных служб
```

Экран обязан работать **полностью офлайн** — координаты берутся с GPS-чипа, не из сети. Это вопрос ответственности продукта, а не фича.

- Карта — главный экран, а не лента. Эндуро — географический продукт; человек мыслит «куда», а не «что нового».
- Bottom sheet с выездами виден сразу — ценность доступна без единого тапа.
- Расстояние «от вас» — важнее длины маршрута на этапе выбора.
- FAB совмещает создание выезда и маршрута — два главных генератора контента.

## 8. Пустые состояния (то, что решает судьбу холодного старта)

| Экран | Пустое состояние | Действие |
|---|---|---|
| Карта без маршрутов в регионе | «В твоём регионе пока 0 маршрутов. Будь первым — импортируй трек и получи значок Первопроходца» | Импорт GPX |
| Лента выездов пуста | «На ближайшие выходные выездов нет. Создай свой — мы позовём 47 райдеров твоего уровня в радиусе 100 км» | Создать выезд |
| Гараж пуст | «Добавь технику — начнём считать, во сколько тебе реально обходится сезон» | Добавить мотоцикл |
| Нет отчётов | «Съезди и расскажи. Первые 3 отчёта в регионе попадают в подборку» | — |

Пустые состояния в продукте с холодным стартом — **не заглушка, а главный инструмент привлечения контента**. Каждое обязано содержать действие и мотив.
