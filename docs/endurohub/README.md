## Три вывода, ради которых написан этот пакет

1. **Чистая эндуро-ниша в РФ — рынок на 80–150 млн ₽ выручки.** Это хороший бизнес, но не венчурный. Архитектура и позиционирование строятся под мульти-вертикальную офроуд-платформу (эндуро → снегоходы → квадро → 4×4), иначе TAM не набирается.
2. **Главный конкурент — не приложение, а привычка обсуждать выезд в Telegram-чате.** Поэтому первый контур продукта — Telegram Mini App, а стратегия роста — партнёрство с админами чатов, а не война с ними.
3. **MVP — это один сценарий, а не десять разделов.** «Увидел выезд рядом → присоединился в два тапа → съездил». Всё остальное откладывается на месяцы 2–9.
