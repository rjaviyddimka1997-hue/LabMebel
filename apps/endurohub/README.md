# EnduroHub — MVP (Telegram Mini App)

Рабочий каркас продукта по документам в [`docs/endurohub/`](../../docs/endurohub/).
Реализован **единственный сценарий MVP** (см. док. 07, раздел 1.1):

> открыл из чата → увидел выезд рядом → присоединился в два тапа → съездил

Всё, что не обслуживает этот сценарий (гараж, каталог сервисов, бронирование,
достижения, фотоотчёты), намеренно отсутствует — оно запланировано на месяцы 2–9.

## Быстрый старт

```bash
cd apps/endurohub
npm install
npm run dev          # http://localhost:5173
```

Без переменных окружения приложение работает **на демо-данных**: 10 маршрутов,
8 выездов, 6 райдеров. Созданные выезды и профиль сохраняются в localStorage.
Это осознанный режим — продукт можно показать админу чата с ноутбука, не
поднимая инфраструктуру.

## Подключение бэкенда

```bash
cp .env.example .env
```

| Переменная | Назначение |
|---|---|
| `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` | Включают режим Supabase вместо демо-данных |
| `VITE_MAP_STYLE_URL` | Стиль карты MapLibre. Без него — растровый OSM-фоллбэк |

Миграция схемы: [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql).
Включает PostGIS, RLS-политики на все таблицы, триггер обрезки приватности
треков и три RPC (`rides_nearby`, `routes_in_bbox`, `join_ride`).

```bash
supabase db push        # или psql -f supabase/migrations/0001_init.sql
```

Авторизация ожидает Edge Function `auth-telegram`, которая проверяет HMAC
подписи `initData` по bot token и возвращает пару токенов Supabase. Проверять
подпись на клиенте нельзя — bot token клиенту недоступен.

**Тайлы OSM в фоллбэке не рассчитаны на продуктовый трафик.** Перед публичным
запуском нужен ключ MapTiler или собственный tile-server.

## Структура

```
src/
  types.ts                 Доменные типы
  session.tsx              Текущий райдер, геопозиция, вход через Telegram
  lib/
    difficulty.ts          Шкала E1–E5 — центральная онтология продукта
    geo.ts                 Гаверсинус, bbox, упрощение RDP, обрезка приватности
    gpx.ts                 Разбор и выгрузка GPX без зависимостей
    telegram.ts            Обёртка над Telegram WebApp SDK
    supabase.ts            Клиент и обмен initData на сессию
    store.ts               Локальное состояние демо-режима
    api.ts                 Единственная граница данных: Supabase либо store
    format.ts              Русские даты, склонения, дистанции
  components/
    MapView.tsx            MapLibre: слои маршрутов и выездов, выбор точки
    LazyMap.tsx            Ленивая загрузка карты отдельным чанком
    ui.tsx  cards.tsx      Бейджи уровня, аватары, карточки, пустые состояния
  screens/                 8 экранов сценария MVP
supabase/migrations/       Схема БД
```

## Ключевые решения

| Решение | Почему |
|---|---|
| Карта — главный экран, а не лента | Эндуро географичен: человек мыслит «куда», а не «что нового» |
| Уровень E1–E5 виден везде | Главный страх новичка — попасть на маршрут не по силам |
| Регистрация только по действию | Смотреть выезды можно без входа; онбординг — в момент «Присоединиться» |
| Чат выезда = группа Telegram | Свой мессенджер — месяц работы и худший UX |
| Трек обрезается на 500 м | Публичный маршрут не должен начинаться у чьего-то гаража |
| MapLibre в отдельном чанке | 800 КБ не должны задерживать первый экран |
| Граница данных одна (`api.ts`) | Экраны не знают, есть ли бэкенд |

## Проверка

```bash
npm run typecheck
npm run build
npm run test:e2e     # требует playwright в окружении; без него шаг пропускается
```

Сквозной прогон (`e2e/smoke.mjs`, 12 шагов) в headless Chromium покрывает: загрузку карты и треков,
фильтр по уровню, открытие карточки выезда, онбординг, вступление в выезд,
мастер создания выезда из 4 шагов, публикацию и сохранение после перезагрузки.

## Чего здесь нет и не будет в Mini App

Офлайн-карты, фоновая запись трека и экран SOS **невозможны в WebView**:
при блокировке экрана ОС убивает JS-поток через 30 секунд. Эти три функции
требуют нативного приложения (React Native, месяцы 4–8 по roadmap). В лесу
без связи это вопрос безопасности, а не удобства.
